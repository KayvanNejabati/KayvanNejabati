# Repository working rules

## Scope boundary

This folder is an independent Git repository (`KayvanNejabati/KayvanNejabati`). It is often
opened alongside sibling repositories in a multi-root VS Code workspace. Do not read from or
write to sibling folders. Every path you touch must resolve inside this repository.

## What this is

The GitHub special profile repository. Its `README.md` renders on the public profile page at
github.com/KayvanNejabati. There is no application code and no test suite.

## Working rules

- This content is public and represents Kayvan personally. Treat every edit as published copy.
- Do not invent credentials, employers, dates, metrics, or project claims. If a fact is not
  already present in the repository or supplied directly, ask rather than fill the gap.
- Keep links live. Check that any badge, shield, or profile URL still resolves before adding it.
- `branding/` holds image assets. Do not rewrite or regenerate them.
- Prose is concise and uses no em dashes.
